# 隐私政策

*最后更新：2026年8月*

本隐私政策说明您在使用本任务管理应用程序（以下简称“本应用”）时，我们如何收集、使用和保护您的个人信息。

---

## 1. 我们收集的信息

### 1.1 您直接提供的信息

* **账户信息**：您注册时提供的姓名、电子邮箱地址和密码

* **个人资料信息**：显示名称

* **任务数据**：您创建的任务的标题、描述、截止日期和状态

### 1.2 自动收集的信息

* **会话数据**：用于保持登录状态的身份验证令牌和会话标识符

* **使用数据**：创建、更新和删除任务等操作的时间戳

### 1.3 来自第三方服务的信息

如果您选择通过 GitHub OAuth 登录，我们将从 GitHub 获取您的 GitHub 用户名、电子邮箱地址和个人头像。我们不会获取您的 GitHub 密码，也不会获得访问您 GitHub 仓库的权限。

---

## 2. 我们如何使用您的信息

我们收集的信息仅用于提供和运营本应用：

* 创建和管理您的账户

* 向您和您的团队成员显示您的个人资料和任务

* 发送与任务活动相关的应用内通知

* 实施基于角色的访问控制（管理员 / 用户）

* 回复您的请求或支持咨询

我们不会将您的信息用于广告，也不会向第三方出售您的数据。

---

## 3. 我们如何共享您的信息

我们不会出售或出租您的个人信息。仅在以下有限情况下，您的信息可能会被共享：

* **与团队成员共享**：您的姓名、头像和任务活动对本应用中其他已通过身份验证的用户可见

* **法律要求**：如果法律要求我们根据合法请求披露相关信息

---

## 4. 数据存储与安全

* 所有数据均存储在托管于私有服务器上的 PostgreSQL 数据库中

* 密码绝不会以明文形式存储；我们使用符合行业标准的算法对密码进行哈希和加盐处理

* 您的浏览器与本应用之间的所有通信均通过 HTTPS 加密

* API 访问需要通过会话令牌或 API 密钥进行身份验证

---

## 5. Cookie 与会话

本应用使用会话 Cookie 来保持您的登录状态。这些 Cookie：

* **属于严格必要的 Cookie**：用于身份验证；如果没有这些 Cookie，本应用将无法正常运行

* **不会用于跟踪或广告**

您可以随时通过浏览器设置删除 Cookie。删除后，您将退出本应用的登录状态。

---

## 6. 数据保留

* 只要您的账户处于有效状态，我们就会保留您的账户数据

* 如果您删除账户，您的个人信息将在 30 天内从我们的系统中删除

* 您创建的任务数据在您的账户被删除后，仍可能对其他团队成员可见，并以“已删除用户”（deleted user）的名义显示

---

## 7. 您的权利

您享有以下权利：

* **访问权**：请求获取我们所持有的您的个人数据副本

* **更正权**：请求更正不准确的数据

* **删除权**：请求删除您的账户及相关数据

* **数据可携权**：以机器可读格式导出您的任务数据

如需行使上述任何权利，请使用下方提供的联系方式与我们联系。

---

我们可能会不时更新本隐私政策。本页面顶部所示日期为本政策最近一次修订的日期。在本政策更新后继续使用本应用，即表示您接受更新后的政策。
